# Coppergate brand mark

Flat geometric gate mark (primary UI / favicon). Horizontal lockups include the wordmark.

| File | Use |
|------|-----|
| `logo.svg` | Mark only (`currentColor`) |
| `logo-black.svg` / `logo-white.svg` | Fixed-fill mark |
| `logo-lockup.svg` | Mark + wordmark (`currentColor`) |
| `logo-lockup-black.svg` / `logo-lockup-white.svg` | Fixed-fill lockups |
| `app-icon.svg` / `app-icon-512.png` / `app-icon-1024.png` | White mark on `#0A0A0A` |
| `logo-128.png` / `logo-512.png` | Raster mark masters |

Wordmark font: **Space Grotesk** (fallback Manrope / system-ui). Load the font in the app for correct SVG text rendering, or convert text to paths for standalone use.

Served copies: [`apps/web/public/`](../apps/web/public/).
