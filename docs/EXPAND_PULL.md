# Expand only on pull

Policy for platform surface expansion after the $1M GTM wedge is locked.

## Default: do not build

| Surface | Status | Unlock when |
|---|---|---|
| Bitbucket / Azure DevOps **live** PR delivery | Deferred | Paying customer blocked without it |
| SSO / SCIM | Skeleton only | Team plan purchase / enterprise pilot |
| Jira / Linear depth (bidirectional polish) | Adapters exist | Customer names them as system of record |
| Sonar / CodeQL / Semgrep breadth | Partial | Fitness pull from security-led teams |
| Org-chart / chat employee UX | Out of category | Never — Paperclip/OpenClaw clones |
| Unattended L3 deploy | Non-goal | Explicit policy product later |

## Allowed without pull

- Reliability/fix for **issue → PR** and **Sentry / CI-fail → PR**
- Hosted billing, onboarding TTFV, recovery UX
- Content / launch kit / shareable reports
- Phase X harden **after** paid retention (pen-test, DR, SLO) for Team trust

## How to record pull

1. Note workspace + plan in invite `note` or Stripe metadata.
2. Open architecture backlog item only after written customer ask.
3. Prefer deepening one adapter over adding a tenth half-adapter.
