## Capability

Coppergate and kprompt (and any other co-hosted workspace) keep **separate monthly envelopes**: every `estimate_reserve` and usage ledger append asserts `workspaceId` against the project (and task when present) before debit. Cross-tenant reserve/append fails closed — envelopes never share debit.
